# Oahu-Rainfall-Watershed-Risk
This project analyzes long-term rainfall trends across Oʻahu’s watersheds primarily using Hawaiʻi Climate Data Portal data. This project identifies drought, flooding, and wildfire vulnerabilities by examining rainfall extremes, integrating temperature data, and mapping Haole Koa distribution as an indicator of environmental stress.
